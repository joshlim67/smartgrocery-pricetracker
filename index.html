Sinkron Otomatis PC & HP

Aplikasi ini menggunakan 1 Database Bersama (Shared Realtime Document). Begitu Anda input barang di PC, layar HP Anda yang sedang membuka web ini akan otomatis langsung ter-update realtime tanpa perlu reload.

Jika belum diisi di file firebase-config.js, Anda dapat menempelkan objek konfigurasi atau JSON di bawah ini:

Pastikan Security Rules Firestore Aktif:

Di Firebase Console → Firestore Database → Tab Rules, gunakan aturan ini agar PC & HP bisa membaca & menulis:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
